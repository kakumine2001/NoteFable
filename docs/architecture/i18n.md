# 界面语言

StudyMate 支持英文、简体中文和日文。首页导航和两个工作区的侧栏底部共用 `LanguageSelect`，匿名用户也能切换语言。界面语言与聊天内容、笔记内容及模型输出语言独立，不改写用户保存的数据。

## 选择顺序

`src/lib/i18n/locale.ts` 是语言选择规则的来源：

1. `studymate-locale` Cookie 中有效的 `en` / `zh` / `ja`。
2. 请求的 `Accept-Language`，按有效 q 权重从高到低选择支持的语言，忽略通配符与 q=0。
3. `x-vercel-ip-country`：CN、TW、HK、MO、SG → 简体中文，JP → 日文。
4. 英文。

地区是浏览器语言不受支持或未提供时的回退。因此人在日本、浏览器首选中文时显示中文。台湾和香港目前同样使用简体中文。地区信息由 Vercel 在线提供，本地没有该头时只依赖 Cookie 和浏览器；开发验证可以在 HTTP 请求中显式提供该头。

手动选项保存在当前浏览器的 Cookie，有效期一年，`Path=/; SameSite=Lax`，HTTPS 下加 `Secure`。选择“自动”删除 Cookie，重新使用浏览器与地区信息。偏好不写入数据库，也不随 Google 登录同步。切换通过 `router.refresh()` 获取新的服务端字典，保留工作区客户端状态和当前草稿。

## 字典和编辑器

首页和 `/app` 放在路由组 `src/app/(localized)/` 下，由它的 `layout.tsx` 调用 `getLocaleState()`，给内容加上对应的 `lang`，并把当前语言的字典传给 `I18nProvider`。根布局 `src/app/layout.tsx` 不读 Cookie 和请求头，所以英文的隐私政策、服务条款仍是静态页面；根布局输出 `<html lang="en">`，`I18nProvider` 挂载后改成当前语言。英文原句就是键；`createTranslator` 提供回退和 `{name}` 插值。`messages/zh.ts`、`messages/ja.ts` 存界面译文，`messages/zh-server.ts`、`messages/ja-server.ts` 存服务端错误文的译文；仅当前语言的字典作为 Provider 的数据传给浏览器。Provider 在语言不变时保持同一个 `t`，`router.refresh()` 不会让依赖 `t` 的处理重新运行。

错误提示在状态里保存英文原句（用 `msg()` 标记）或 API 返回的文字，显示时再调用 `t()`，切换语言后会跟着变。服务端在 `error` 字段和 `new …Error()` 中返回的固定句子也用 `msg()` 标记，界面显示时按字典翻译。附件校验这类带文件名和数字的句子由 `src/lib/client-files.ts` 接收 `t` 生成；工作区把它保存为按当前 `t` 生成文字的函数。

客户端通过 `useT()` 或 `useI18n()` 翻译。常量表中的待翻译文字用 `msg()` 标记，并在渲染时调用 `t()`。完整句子应作为一个键；需要插入按键、强调或高亮时，保留 `{key}` / `{term}` 等占位符后插入 React 节点，不把句子拆成英文语序的碎片。

日期使用当前语言的 BCP 47 标签。BlockNote 内置菜单随界面语言使用其官方字典；切换时用当前笔记草稿重新挂载编辑器，重置选区和编辑器内的撤销栈，但保留自动保存队列中的内容。表情选择器也使用对应的语言数据和标签。

品牌名、模型名、文件名和用户自己的标题保持原样。隐私政策与服务条款正文保持英文并标注 `lang="en"`；导航链接翻译。AI 生成的回答、思考摘要、工具返回的描述、上游服务的原始错误，以及服务端拼接了变量的少数错误文（如搜索长度、名称长度）不由界面字典重写。

## 验证

`src/lib/i18n/*.test.ts` 验证语言优先级、地区回退、服务端请求读取、插值安全，以及从非测试源码的 `t("…")` / `msg("…")` 提取出的每个键在两个字典中都有译文且占位符一致。新增界面文案时同步补两种译文。动态键来自常量表时先用 `msg()` 标记。

相关修改需运行 `npm test`、`npm run typecheck`、`npm run lint`，并在浏览器核对首页、侧栏、手机布局以及打开笔记时的语言切换。HTTP 验证能确认服务端选择和渲染内容，不能证明控件交互或布局正确。
